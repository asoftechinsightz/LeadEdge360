# LeadEdge360 Demo Deck — Canva Build Guide

**Use this file to build slides in Canva in ~30 minutes.**

| Setting | Value |
|---------|--------|
| Canva template search | "Tech pitch deck" or "SaaS presentation" |
| Slide size | 16:9 widescreen |
| Primary color | `#0066FF` |
| Background / dark | `#0A1F44` |
| Accent / success | `#22C55E` |
| Font (headings) | Inter Bold or Montserrat Bold |
| Font (body) | Inter Regular or Open Sans |
| Logo | Upload `public/images/brand/asoftechinsightz-logo.svg` + `leadedge360-logo.svg` |

**Presenter:** Founder / sales lead  
**Duration:** 20–25 min (12 slides + live demo)  
**Goal:** Book pilot or send proposal within 48 hours

---

## How to build in Canva

1. Create new **Presentation (16:9)**.
2. Set brand kit: Primary `#0066FF`, Secondary `#0A1F44`, Accent `#22C55E`.
3. Create **12 slides** using sections below — copy **ON SLIDE** text into text boxes; keep **SPEAKER NOTES** in Canva's presenter notes panel (View → Show notes).
4. Add screenshots from your live VPS demo on Slides 5, 6, 10 (optional but strong).
5. Export PDF + present from Canva or download for Google Meet screen share.
6. Generate QR on Slide 12 → `https://asoftechinsightz.com/growth-audit`

## Appendix A — Objection handling (keep off slides, in notes)

| They say | You say |
|----------|---------|
| "We use Zoho/HubSpot" | "Strong tools for global scale. We're GST-native, AI agents included, India pricing — and I'll show you our own pipeline live in 10 minutes." |
| "Too expensive" | "Fair. One lost deal/month often exceeds ₹50k. Pilot at 50% lets you prove ROI in 90 days before full price." |
| "Need customization" | "Enterprise includes industry profiles. Pilot starts standard — we customize from real usage, not guesses." |
| "Security / data?" | "Multi-tenant isolation, DPDP-aware capture. Enterprise can discuss dedicated VPS." |
| "Need to think" | "Absolutely. I'll send a proposal today. Can we book 15 minutes on [Tuesday 11am] to answer questions?" |
| "Send me info" | "I'll send a one-pager and proposal. What decision timeline are you working with?" |
